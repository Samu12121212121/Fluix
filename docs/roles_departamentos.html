⚡ Flujo Custom Claims (Firebase Auth)

Admin asigna rol/dept
formulario_empleado_form.dart
→
Firestore escribe
usuarios/{uid}
→
CF trigger
actualizarClaimsEmpleado
→
Firebase Auth
setCustomUserClaims(uid, {nivel, dept})
→
Firestore Rules
request.auth.token.nivel ≤ 2

¿Por qué Custom Claims? Los claims viajan dentro del JWT de Firebase Auth. Firestore Rules los lee con request.auth.token.nivel sin ninguna consulta extra — crítico a 2.700+ empleados donde cada query adicional se multiplica por todas las lecturas simultáneas.
