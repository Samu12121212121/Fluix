Fluix Web SDK

Guía de referencia — atributos data-fluix-*

Versión 2.0 · 2026
fluix.app

¿Cómo funciona?

Copia el script SDK desde Fluix → Integración Web y pégalo antes del </body> en cada página. Luego añade divs con atributos data-fluix-* donde quieras mostrar contenido. El SDK detecta automáticamente qué módulos hay en la página, los conecta con Firestore y actualiza el HTML en tiempo real. Cualquier cambio desde la app se refleja en la web al instante sin tocar código.

Módulos disponibles
data-fluix-agenda Lista de eventos en tiempo real (presentaciones, ferias, talleres…)
<div data-fluix-agenda data-fluix-limite="10" data-fluix-tipo="Presentación" data-fluix-ciudad="Granada" data-fluix-detalle-url="evento.html?evento="> </div>
data-fluix-limite Máx. de eventos (por defecto 50) data-fluix-tipo Filtrar: Presentación, Feria, Taller, Lectura… data-fluix-ciudad Filtrar por ciudad data-fluix-detalle-url Prefijo URL de detalle
data-fluix-agenda-detalle Evento completo — se activa cuando la URL contiene ?evento=ID
<div data-fluix-agenda-detalle> <h1 data-fluix-campo="titulo"></h1> <p data-fluix-campo="descripcion"></p> <img data-fluix-campo="imagen_url" alt=""> <span data-fluix-campo="fecha_fmt"></span> <span data-fluix-campo="lugar"></span> <a data-fluix-campo="url_inscripcion">Inscribirse</a> </div>
ℹ El título se inyecta automáticamente en <title>, meta description y JSON-LD Event para Google.
data-fluix-catalogo Catálogo de libros / productos — conectado al catálogo de Fluix
<div data-fluix-catalogo data-fluix-limite="20" data-fluix-categoria="Novela" data-fluix-detalle-url="libro.html?item="> </div>
data-fluix-limite Máx. de items data-fluix-categoria Filtrar por categoría data-fluix-detalle-url Prefijo URL de detalle
data-fluix-catalogo-detalle Ficha completa de un libro/producto — se activa con ?item=ID en la URL
<div data-fluix-catalogo-detalle> <img data-fluix-campo="imagen_url" alt=""> <h1 data-fluix-campo="nombre"></h1> <p data-fluix-campo="descripcion"></p> <span data-fluix-campo="precio"></span> <a data-fluix-campo="stripe_link">Comprar</a> </div>
ℹ Inyecta JSON-LD Product automáticamente para SEO.
data-fluix-blog Lista de artículos y noticias del blog — requiere un <template> dentro
<div data-fluix-blog data-fluix-limite="9" data-fluix-tipo="noticia"> <template data-fluix-blog-card> <article> <img data-fluix-campo="imagen_url" alt=""> <h3 data-fluix-campo="titulo"></h3> <p data-fluix-campo="resumen"></p> <a data-fluix-campo="link">Leer más</a> <span data-fluix-campo="fecha"></span> </article> </template> </div>
data-fluix-tipo Filtrar: articulo | noticia | entrevista | resena
data-fluix-blog-post Artículo completo — se activa cuando la URL contiene ?post=slug
<div data-fluix-blog-post style="display:none"> <img data-fluix-campo="imagen_url" alt=""> <h1 data-fluix-campo="titulo"></h1> <div data-fluix-campo="contenido"></div> <!-- Markdown → HTML --> <span data-fluix-campo="autor"></span> <span data-fluix-campo="fecha"></span> </div>
ℹ Si el artículo tiene varias imágenes, se renderizan como carrusel. Inyecta JSON-LD Article + meta OG automáticamente.
data-fluix-seccion="ID" Sección personalizada — ID es el identificador de la sección en Fluix → Contenido Web
<!-- Modo plantilla: el SDK crea/elimina nodos dinámicamente --> <div data-fluix-seccion="autores"> <template data-fluix-plantilla> <div> <img data-fluix-campo="imagen_url" alt=""> <h3 data-fluix-campo="nombre"></h3> <p data-fluix-campo="descripcion"></p> </div> </template> <div data-fluix-lista></div> </div> <!-- Modo clásico: actualiza elementos existentes en el HTML --> <div data-fluix-seccion="horarios"> <span data-fluix-item="lunes"> <b data-fluix-campo="nombre"></b> <span data-fluix-campo="horario"></span> </span> </div>
data-fluix-seleccion-nazari Selección editorial Nazarí — exclusivo cuenta Editorial Nazarí
<!-- Carrusel en el index (5 libros) --> <div data-fluix-seleccion-nazari data-fluix-limite="5"> <template data-fluix-item> <div class="fluix-naz-item"> <img data-fluix-campo="imagen_url" alt=""> <h3 data-fluix-campo="titulo"></h3> <span data-fluix-campo="autor"></span> <p data-fluix-campo="nota_editorial"></p> </div> </template> </div> <!-- Página completa (todos los libros) --> <div data-fluix-seleccion-nazari data-fluix-limite="50"> <template data-fluix-item>...</template> </div>
data-fluix-limite Máx. de libros (por defecto 50) data-fluix-libro-del-mes="true" Solo muestra el libro del mes
ℹ Los libros se gestionan desde Fluix → Selección Nazarí. Se ordenan por el orden definido en la app. Ver plantillas en public_web_visor/nazari_index.html y nazari_seleccion.html.
data-fluix-contacto Formulario de contacto → los mensajes llegan a Fluix → Mensajes
<!-- El SDK genera el formulario completo automáticamente --> <div data-fluix-contacto data-fluix-titulo="Escríbenos"></div> <!-- O usa tu propio <form> y el SDK lo conecta --> <div data-fluix-contacto> <form> <input name="nombre" required> <input name="email" type="email" required> <textarea name="mensaje" required></textarea> <button type="submit">Enviar</button> </form> </div>
data-fluix-resenas Valoraciones de clientes sincronizadas desde Fluix
<div data-fluix-resenas data-fluix-limite="5"></div>
data-fluix-push Botón para activar notificaciones push web
<div data-fluix-push data-fluix-texto="Activar alertas"></div>
ℹ Requiere configurar la VAPID key en Fluix → Integración Web y subir /firebase-messaging-sw.js a la raíz del dominio.

Notas importantes

  • El script detecta automáticamente qué módulos hay en la página y solo carga lo necesario.
  • Cualquier cambio en la app (activar/desactivar, editar contenido) se refleja en la web en tiempo real sin tocar código.
  • Puedes combinar varios módulos en la misma página — cada uno escucha su propia colección en Firestore.
  • Los módulos de detalle (agenda-detalle, blog-post, catalogo-detalle) leen el ID/slug de la URL automáticamente.
  • El SEO (title, meta, JSON-LD) se inyecta en el <head> solo cuando se carga un detalle, sin afectar al resto de la página.
  • Para data-fluix-seccion: usa modo plantilla cuando quieras que el SDK cree los nodos dinámicamente. Usa modo clásico si el HTML ya tiene los elementos y solo quieres actualizar sus campos.
